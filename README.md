
# SOZAN / NAZM – Android Shopping App

A contemporary Indian wear shopping app built with React Native and Expo, connected to a Next.js e-commerce backend.

## 📱 Download Android App

[**Download SOZAN / NAZM APK – v1.0.0**](https://github.com/AndroidPayal/ai-clothing-store-mobile/releases/tag/v1.0.0)

Download the APK from GitHub Releases and install it on your Android device.

## 🌐 Live Website

https://ai-clothing-store-seven.vercel.app/

## ✨ Features

- User registration and login
- Browse products and categories
- Product search
- Shopping cart and quantity management
- Wishlist
- Checkout and Razorpay payment integration
- Order history and order details
- User profile and sign out
- Backend API integration

## 🛠️ Tech Stack

- React Native
- Expo
- TypeScript
- Expo Router
- Axios
- React Context API
- AsyncStorage
- Expo Secure Store
- Razorpay
- REST API
- Next.js backend
- MongoDB

## 🚀 Run Locally

Clone the repository:

```bash
git clone https://github.com/AndroidPayal/ai-clothing-store-mobile.git
cd ai-clothing-store-mobile
npm install
```

Start the Expo development server:

```bash
npx expo start
```
